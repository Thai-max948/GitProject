# GitProject

Đây là dự án thực hành Git và GitHub trong khóa học Web Frontend.

## Cấu trúc

- `source/index.html`: trang giới thiệu dự án.
- `source/news.html`: trang tin tức mẫu.

## Quy trình Git

- `git clone <URL>`: sao chép repository từ GitHub về máy.
- `git add README.md`: đưa README vào staging.
- `git commit -m "Add README.md"`: lưu thay đổi thành một commit.
- `git push origin main`: đẩy commit của nhánh main lên GitHub.
- `git add source/`: đưa các trang HTML trong thư mục source vào staging.
- `git commit -m "Add source files"`: lưu các trang nguồn vào lịch sử Git.
- `git push origin main`: đồng bộ commit mới lên GitHub.

## Chạy thử

Mở `source/index.html` bằng trình duyệt. Trang chủ có liên kết sang trang tin tức mẫu.
